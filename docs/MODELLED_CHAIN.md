# Модельный контур АВТ → гидроочистка → блендинг

Контур отделён от historical replay и не выдаёт результаты за промышленные уставки.
Все входы редактируются, а системный и операторский варианты проходят одну функцию
оценки. Горизонт фиксирован на 180 минутах.

## Расчёт

1. Исправленные формулы ВАК вычисляются только при наличии всех входов. Для АВТ
   применяется подтверждённая группировка `F65/F32 + F30`.
2. Сера после гидроочистки рассчитывается экспериментальной линейной функцией сырья
   и P8/T11/F19. Коэффициенты видимы в `config/modelled.yaml`; причинный эффект
   историей не доказан, а единицы управлений не подтверждены.
3. Сначала проверяются train-only диапазоны и верхняя граница интервала серы.
   Только допустимые варианты ранжируются по proxy затрат и качества.
4. Рецепт перебирается с шагом 5%. Сера, T95 и цетановое число смешиваются линейно;
   эффект 2-EHN задаётся консервативной моделью. Проверки спецификации обязательны.
5. Request и полный result атомарно сохраняются в отдельной таблице `modelled_runs`.

При пропуске обязательного качества или свежести более 240 минут возвращается
`insufficient_data`. Если обязательные проверки не проходит ни один вариант —
`no_feasible_option`. Допустимый baseline даёт `no_change`; иной победитель —
`change_recommended`.
